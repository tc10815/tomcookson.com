Projects

  • ParkEz AI (2023)
    • ParkEz AI uses computer vision and ML with security camera footage to monitor parking lot occupancy.
    • The concept was developed as a part of a 9 person group project, but I implemented the idea myself the summer before the group would implement it.
    • Since I was unfamiliar with many of the technologies need for the site, I used the project as a test to see how much AI could assist a programmer in an unfamiliar environment. I meticulously documented all of my interactions with AI and was impressed by how powerful it was.
  • Typing Dvorak: A Javascript remake of Dan Wood's ABCD A Basic Course in Dvorak (2022/2006)
    • This tutor teaches learners how to touch type using the "Dvorak" keyboard layout, a more efficient alternative standard QWERTY Keyboards.
    • Content is adapted from a simple, static HTML type course by Dan Wood in 1995.
    • I wrote the Javascript version in 2022, but I made the first version in Adobe Flash with Actionscript in 2006, the summer after I graduated High School.
