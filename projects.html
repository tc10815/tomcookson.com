  • Typing Dvorak: A Javascript remake of Dan Wood's ABCD A Basic Course in Dvorak (2022/2006)
    • This tutor teaches learners how to touch type using the "Dvorak" keyboard layout, a more efficient alternative standard QWERTY Keyboards.
    • Content is adapted from a simple, static HTML type course by Dan Wood in 1995.
    • I wrote the Javascript version in 2022, but I made the first version in Adobe Flash with Actionscript in 2006, the summer after I graduated High School.
  • Dispatches from an American Student Studying Abroad in Dubrovnik, Croatia (2022/2008)
    • When I studied abroad in Croatia in 2008 we all had to keep a blog; I used a Wordpress blog on this website(original blog). I stopped maintaining it for 14 years and naturally it stopped working since technology on the server advanced and the code stayed the same.
    • In 2022 I recreated the 2008 Wordpress website into an easy-to-maintain static webpage. Although I used a lot of the same assets, CSS and HTML as the original I made it look more modern and added a bit of content.
